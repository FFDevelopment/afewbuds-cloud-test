# Historical workflow archive

One-off investigations, obsolete patch builders and superseded validation jobs were moved here when mobile 3D v12 became main. These files are not active GitHub Actions workflows. Current release entry points are `.github/workflows/mobile-3d-preview.yml` (build and validate main) and `deploy-pages.yml` (publish the validated baseline).

Historical tools, runtime recipes and base packs outside this folder remain reproducibility inputs. Do not remove them merely because their names reference older releases.
