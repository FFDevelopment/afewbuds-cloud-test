# AFewBuds candidate build

Both `experiment/container-inventory` branches now use the same account cloud career. Main is unchanged.

Sign in with the same account on mobile and desktop. A device switch requests a final save from the old game, then loads that shared save. Offline/unresponsive sessions time out; their later writes are rejected. Guests remain local. Older builds cannot write to a career after it activates the protected shared-session protocol.

The original account career is backed up on the server at first activation. Earlier isolated test saves remain untouched on their original devices; they are not silently uploaded over the account career.

Save & Quit waits for cloud acknowledgement and releases the active play session. Browser tabs that cannot close show a saved screen; sign in again to restart.

Backpack, storage, property agreements, purchased upgrades, genetics, story and first-day tutorial state are included in the shared save. Desktop camera preferences remain device-specific.

Tutorial: movement, phone, backpack, buy seeds, buy fertilizer, collect, plant, water, fertilize, harvest, trim, pack, carry, store, computer, sell. Water and fertilizer instantly mature only the lesson crop. Mobile Phone > Pause opens Resume, Settings, Help and Save & Quit. Desktop D-pad Up opens Phone; D-pad Right opens Backpack.
